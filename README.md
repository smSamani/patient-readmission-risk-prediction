# Healthcare Patient Readmission Risk Prediction System

## Project Overview
This project builds a machine learning decision support system to predict 30-day patient readmission risk using historical clinical and administrative data.

## Structure
- `data/raw` - raw input data (do not commit sensitive data)
- `data/processed` - cleaned and transformed data
- `notebooks` - EDA and experiments
- `src` - pipeline code (`preprocess.py`, `train.py`, `evaluate.py`, `predict.py`, `explain.py`)
- `dashboard` - Looker Studio assets/docs
- `models` - trained model artifacts
- `reports` - figures and evaluation outputs
